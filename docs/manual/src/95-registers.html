I/O register summary

This appendix lists every register in the cartridge and console I/O space, grouped by the chip that decodes it, in address order. All registers are 16 bits wide at even addresses; byte access is described in . Unused addresses within each range read 0 and ignore writes. Every name in this appendix is predefined in CYASM as the register's address.

Access: R readable, W writable, R/W both. Reset values are 0 unless the description gives another value.
